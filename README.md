# LaoDeer 작업실 (시안)

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 보입니다.

## 파일

원래 사이트(laodeer.qshop.ai)의 뼈대를 따릅니다. 상단 메뉴: HOME / ABOUT / GAMES / DEVLOG / PRESS KIT / SOCIALS / FAQ

| 파일 | 내용 |
|---|---|
| `admin.html` | **관리 화면** (기록, 게임, 스튜디오 정보 쓰기·고치기·지우기) |
| `index.html` | HOME: 흐린 게임 장면 위 슬로건, OUR GAMES, 최근 작업 기록 |
| `about.html` | ABOUT: 스튜디오 문장, 팀, 소개, 만드는 기준에 관한 글, 낙서장 |
| `games.html` | GAMES: 게임 카드 (공개 예정은 Coming Soon 카드) |
| `game.html?id=soul` | 게임 상세와 그 게임의 기록 |
| `devlog.html` | DEVLOG: 작업 기록 전체 (개발일지, 생각, 그림) |
| `presskit.html` | PRESS KIT: 게임별 팩트 시트와 이미지 |
| `socials.html` | SOCIALS |
| `faq.html` | FAQ |
| `data/records.js` | 작업 기록 |
| `data/games.js` | 게임 정보 (목록 순서 = 화면 순서) |
| `data/itch.js` | itch.io에서 자동으로 가져온 개발일지 (직접 고치지 않음) |
| `tools/sync-itch.mjs` | itch.io 개발일지를 가져오는 스크립트 |
| `data/studio.js` | 슬로건, 첫 화면 장면, 로고, 스튜디오 문장, 팀, 소셜, FAQ, 프레스 연락처 |

| `assets/js/site.js` | 데이터를 읽어 화면을 그림. 상단 메뉴 목록(NAV)도 여기 있어요 |
| `assets/js/fx.js` | 움직임과 놀이 요소 |
| `assets/examples/` | 시안용 예시 이미지 (교체 대상) |

## 움직임과 놀이 요소

- **그림 크게 보기**: 그림이나 스크린샷을 누르면 크게 열려요. 휠이나 두 손가락으로 확대하고, 끌어서 옮기고, 좌우로 밀거나 ← → 키로 넘겨요.
- **첫 화면**: 들어오면 장면이 흐릿한 데서 초점이 맞춰지며 슬로건이 떠올라요. 마우스와 스크롤에 따라 장면이 천천히 움직여요.
- **게임 카드 기울이기**: 게임 카드와 대표 장면이 마우스를 따라 살짝 기울고 빛이 지나가요. Coming Soon 카드에는 빛이 천천히 지나가요.
- **모바일 메뉴**: 오른쪽 위 버튼을 누르면 메뉴가 화면 가득 펼쳐져요.
- **키보드**: J/K로 기록 사이 이동, 1~4로 분류 고르기, ?로 단축키 보기.
- **효과음**: 아래 띠의 "효과음"으로 켜요. 기본은 꺼짐이고 설정은 기억돼요. 소리 파일 없이 브라우저에서 합성합니다.
- **로고**: 마우스를 올리면 글자가 하나씩 튀어요.
- **낙서장**: 소개 페이지에서 방문자가 그림을 그리고 이미지로 저장할 수 있어요. 서버로 보내지 않아요.
- **숨은 커맨드**: ↑↑↓↓←→←→BA
- 기기에서 "동작 줄이기"를 켠 사람에게는 움직임 효과가 꺼져요.

## 관리하기: admin.html

글 쓰기, 고치기, 지우기, 그림 올리기, 게임 정보, 첫 화면 슬로건과 배경 장면, 팀, 소셜, FAQ 고치기는 전부 **관리 화면**에서 합니다. (탭: 기록 / 게임 / 스튜디오) 파일을 직접 열 필요가 없어요.

### 처음 한 번

1. **크롬이나 엣지**로 `admin.html`을 엽니다. (파일을 브라우저로 끌어다 놓아도 돼요. 즐겨찾기에 넣어두면 편해요.)
2. **폴더 열기**를 누르고 이 `laoDeer_web` 폴더를 고릅니다.
3. 브라우저가 "파일을 수정하도록 허용할까요?"라고 물으면 **허용**합니다.

다음부터는 **지난번 폴더 다시 열기** 한 번이면 돼요.

### 기록 올리기

1. **새 기록 쓰기**를 누릅니다.
2. 분류를 고르고, 날짜(오늘로 미리 들어가 있어요)와 본문을 씁니다. 여기까지가 필수예요.
3. 그림이 있으면 이미지 칸에 끌어다 놓거나, 복사한 이미지를 **Ctrl+V**로 붙여넣습니다. 그림을 넣으면 분류가 자동으로 "그림"이 돼요.
4. 오른쪽 미리보기로 사이트에서 보일 모습을 확인하고 **저장**(또는 **Ctrl+S**)을 누릅니다.

- 고치기: 왼쪽 목록에서 기록을 누르고 고친 뒤 저장.
- 지우기: 기록을 연 뒤 **이 기록 지우기**.
- 그림은 `images/연도/` 폴더로 복사돼요. 3MB가 넘는 큰 그림은 긴 변 2400px로 줄여서 저장해요.
- 시안에 있던 예시는 목록 아래 **예시 자료 한 번에 지우기**로 한꺼번에 지울 수 있어요. 직접 쓴 것은 남아요.

### 실수했을 때

저장할 때마다 바로 전 파일이 `_backup/` 폴더에 남아요(파일마다 최근 30개). 되살리려면 원하는 시점의 백업 파일을 `data/` 폴더에 복사하고, 이름을 `records.js`(또는 `games.js`, `studio.js`)로 바꾸면 됩니다. 아래의 GitHub를 쓰면 모든 변경 기록이 남아서 그쪽에서도 되돌릴 수 있어요.

## itch.io 개발일지 연동

itch.io에 올린 개발일지를 이 사이트 DEVLOG에 그대로 보여줘요. 여기서 쓴 기록과 섞여 날짜순으로 나오고, `itch.io` 표시가 붙어요.

- **연결하는 법:** 관리 화면 → 게임 탭 → 그 게임의 **itch.io 게임 주소**에 `https://laodeer.itch.io/게임이름`을 적고 저장. (Sleeve it!은 연결해 두었어요.)
- **가져오는 때:** GitHub가 **6시간마다** 자동으로 새 글을 확인해서, 있으면 `data/itch.js`에 넣고 사이트를 다시 만들어요.
- **바로 가져오기:** GitHub 저장소 → **Actions** 탭 → "itch.io 개발일지 가져오기" → **Run workflow**. 또는 이 폴더에서 `node tools/sync-itch.mjs`를 실행하고 올리기(Commit, Push).
- **보이는 모습:** 제목, 대표 그림, 첫 문장들이 먼저 나오고 **이어 읽기**를 누르면 본문 전체(제목, 그림, 접힌 내용까지)가 펼쳐져요. 그림은 itch.io 이미지 서버의 원본을 그대로 불러와서 itch와 똑같이 보이고, 눌러서 크게 볼 수 있어요.
- **같은 글을 여기에도 썼다면:** 제목이 같은 글은 itch에서 가져온 쪽만 보여줘요.
- **itch에서 글을 고쳤다면:** 이미 가져온 글은 다시 가져오지 않아요. 고친 내용을 반영하려면 `node tools/sync-itch.mjs --all`을 실행하고 올려주세요.
- **itch에서 글을 지웠다면:** 여기서는 자동으로 지워지지 않아요. `data/itch.js`에서 그 글을 지워주세요.
- itch의 오디오나 영상 같은 삽입물은 "영상 보기" 링크로 바뀌거나 빠질 수 있어요.

## 사이트 공개하기 (GitHub Pages)

이 사이트는 이미 공개되어 있어요.

- 사이트 주소: https://seongmini2.github.io/laodeer/
- 저장소: https://github.com/Seongmini2/laodeer (공개 저장소, main 브랜치를 그대로 내보냄)

관리 화면에서 저장하면 **내 PC의 폴더**만 바뀝니다. 인터넷 사이트에 반영하려면 바뀐 파일을 GitHub에 올려야 해요. 올리고 1~2분 뒤 사이트에 반영돼요.

### 방법 1: GitHub Desktop (버튼으로)

처음 한 번:
1. [GitHub Desktop](https://desktop.github.com)을 설치하고 Seongmini2 계정으로 로그인합니다.
2. **File → Add local repository**로 이 `laoDeer_web` 폴더를 고릅니다. (이미 저장소라서 바로 추가돼요.)

그 뒤로 매번:
1. `admin.html`에서 쓰고 저장.
2. GitHub Desktop 왼쪽 아래 칸에 "새 그림"처럼 짧게 적고 **Commit to main**.
3. **Push origin**.

### 방법 2: 명령어 한 줄씩

이 폴더에서 터미널(PowerShell)을 열고:

```powershell
git add -A
```

```powershell
git commit -m "새 기록"
```

```powershell
git push
```

알아두기
- 공개된 사이트에도 `admin.html`이 같이 올라가지만, 이 화면은 **그걸 연 사람의 PC 폴더**만 고칠 수 있어서 다른 사람이 사이트를 바꿀 수는 없어요.
- `_backup/` 폴더는 `.gitignore`에 들어 있어서 GitHub에 올라가지 않고 내 PC에만 남아요. GitHub 쪽에는 커밋마다 모든 변경 기록이 남아서, 저장소 페이지의 History에서 예전 상태를 볼 수 있어요.
- 개인 도메인(laodeer.com 같은)을 연결하려면 저장소 **Settings → Pages → Custom domain**에 도메인을 적고, 도메인 업체에서 DNS를 GitHub Pages로 연결하면 돼요.

## 파일로 직접 고치기 (참고)

관리 화면 대신 `data/records.js`를 직접 고칠 수도 있어요. 목록에 한 줄을 넣으면 되고, 날짜순 정렬은 자동이에요.

```js
{ date: "2026-11-27", type: "생각", body: "오늘은 색을 하나 덜어냈다." },
```

- `type`: `"개발일지"`, `"생각"`, `"그림"` 중 하나
- `body`: 빈 줄로 문단을 나누고, `- `로 시작하는 줄은 목록이 됩니다. 개발일지에서는 이 목록에 "바꾼 점"이 붙어요.
- 넣고 싶을 때만: `title`, `image`, `alt`, `game`(게임 id)

보여주는 방식
- **그림**: 이미지를 원본 비율대로 보여주고, `body`를 캡션으로 씁니다.
- **개발일지**: 제목, 스크린샷, 메모, 바꾼 점 순서로 보여줍니다.
- **생각**: 제목이 있으면 제목과 첫 문장을 보여주고 "이어 읽기"로 나머지를 펼칩니다. 제목이 없으면 전부 보여줍니다.

## 예시 자료 바꾸기

- `example: true`가 붙은 항목은 화면에 점선으로 "예시" 표시가 나옵니다. 관리 화면의 **예시 자료 한 번에 지우기**로 한꺼번에 지우거나, 하나씩 열어 "예시 표시 유지" 체크를 풀고 저장하세요.
- 색은 팀 색 세 가지(`--green` #06331E, `--amber` #FDA828, `--cream` #FEEFD7)만 씁니다. `style.css` 맨 위에서 바꿀 수 있어요. 앰버는 글자색으로 쓰지 않고 바탕·밑줄·표시에만 씁니다.
